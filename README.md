# Ardian Danny — Portfolio

Personal portfolio for Ardian Danny, cybersecurity practitioner, product security engineer, mentor, and Executive Director of NoxGuard.

## Design

- Editorial, light paper-and-ink visual system with acid-green accent
- Responsive, accessible HTML/CSS/JavaScript with no framework or build step
- Personalized profile, client-facing security experience, certifications, education, and community work
- Public links limited to NoxGuard and Medium; confidential company and client projects are intentionally not listed
- Portrait stored locally at `assets/danny-portrait.webp`
- Responsive mobile navigation, focus states, active section state, subtle reveal motion, and reduced-motion support

Open `index.html` directly, or serve the directory as a static site. No build step.
